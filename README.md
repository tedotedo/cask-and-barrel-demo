# Cask & Barrel – design concept demo

This is an **unofficial concept demo** of what a website for a Yarm pub could look like.
All menu, hours, events and other content is **placeholder** and must be confirmed by the business.
It is **not affiliated with, approved by, or operated by Cask & Barrel**. The enquiry form does not send anything.
